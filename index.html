Sessão e Segurança

Sincronização entre dispositivos (JSONBin)

Os dados ficam guardados num bin do JSONBin, tal como no site das compras. Usa o mesmo ID em todos os dispositivos e eles passam a mostrar a mesma informação.

Como criar o bin (1 minuto)
  1. Em jsonbin.io, entra na tua conta e carrega em Create Bin.
  2. Escreve {"sidera":true}, guarda, e copia o Bin ID.
  3. Cola-o aqui, em cada dispositivo. Não uses o ID do site das compras: ia apagar essa lista.

Quem souber o ID de um bin público consegue ler os dados. Se quiseres proteger, cria o bin como privado e usa a Master Key.
